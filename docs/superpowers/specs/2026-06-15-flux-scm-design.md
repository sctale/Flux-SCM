# Flux-SCM 设计方案

## 1. 项目概述

### 1.1 项目定位

Flux-SCM 是面向小批量多品种采购场景的物料与供应商管理平台，运行于 Windows 桌面环境。系统以 **卡拉杰克矩阵（Kraljic Matrix）** 为核心方法论，实现供应商科学分类与差异化管控，解决小批量采购中"话语权弱、管理粗放、风险难控"的行业痛点。

### 1.2 核心问题

| 痛点 | 描述 |
|------|------|
| 供应商管理粗放 | 多品种小批量模式下，对所有供应商采取统一管理，无法"对症下药" |
| 话语权不足 | 采购量小，难以成为供应商核心客户，合作中缺乏议价能力 |
| 信息孤岛 | 采购、库存、供应商数据分散在Excel/微信/邮件中，无法联动分析 |
| 风险不可见 | 供应商资质过期、交付延迟、质量异常等问题无法提前预警 |
| 物料编码混乱 | 一物多码、错发错用频发，缺乏统一编码体系 |

### 1.3 目标用户

- 1-10人采购/供应链团队
- 制造业/加工业/科研院所等小批量多品种采购场景
- 单机或局域网部署

## 2. 系统架构

### 2.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 桌面框架 | Electron 33+ | 打包为 Windows exe，支持自动更新 |
| 前端框架 | React 18 + TypeScript | 组件化开发，类型安全 |
| UI 组件库 | Ant Design 5 | 企业级专业UI，丰富的数据展示组件 |
| 图表库 | ECharts 5 | 专业数据可视化，支持雷达图/矩阵图/仪表盘 |
| 状态管理 | Zustand | 轻量级，适合中小型应用 |
| 数据库 | SQLite (better-sqlite3) | 零配置嵌入式数据库，适合1-10人单机/局域网场景 |
| ORM | Drizzle ORM | 类型安全，轻量，SQLite支持好 |
| 构建工具 | Vite + Electron Builder | 快速构建与打包 |

### 2.2 架构分层

```
┌─────────────────────────────────────────────┐
│              Electron 主进程                  │
│  (窗口管理 / 文件系统 / 自动更新 / 打印)      │
├─────────────────────────────────────────────┤
│              渲染进程 (React)                 │
│  ┌──────────┬──────────┬──────────────────┐  │
│  │ 仪表盘   │ 供应商   │ 采购 / 物料 / .. │  │
│  └──────────┴──────────┴──────────────────┘  │
├─────────────────────────────────────────────┤
│            数据服务层 (IPC Bridge)            │
│  (CRUD / 业务逻辑 / 数据校验 / 导入导出)      │
├─────────────────────────────────────────────┤
│            SQLite 数据库                      │
│  (供应商 / 物料 / 订单 / 绩效 / 风险)         │
└─────────────────────────────────────────────┘
```

### 2.3 数据库设计（核心表）

- **suppliers** — 供应商主数据（名称、类别、资质、联系方式、状态）
- **supplier_qualifications** — 供应商资质证书（类型、有效期、附件）
- **supplier_categories** — 卡拉杰克矩阵分类（战略/杠杆/瓶颈/非关键）
- **materials** — 物料主数据（编码、名称、规格、单位、分类）
- **material_suppliers** — 物料-供应商关联（报价、交期、最小起订量）
- **purchase_orders** — 采购订单（订单号、供应商、状态、金额）
- **order_items** — 订单明细（物料、数量、单价、交期）
- **deliveries** — 到货记录（订单、到货日期、数量、质检结果）
- **supplier_performances** — 供应商绩效评分（质量/交付/服务/成本）
- **risk_alerts** — 风险预警（类型、级别、供应商、状态）
- **supplier_contacts** — 供应商联系人

### 3.2 供应商全生命周期管理（核心模块）

基于行业最佳实践，供应商管理遵循 **准入 → 评估 → 分类 → 管控 → 退出** 全流程：

```
┌─────────┐    ┌─────────┐    ┌──────────┐    ┌──────────┐    ┌─────────┐
│  准入    │───→│  评估    │───→│  分类     │───→│  管控     │───→│  退出   │
│ Onboard │    │ Evaluate│    │ Classify │    │ Control  │    │ Exit    │
└─────────┘    └─────────┘    └──────────┘    └──────────┘    └─────────┘
   资质审核       绩效评分      Kraljic矩阵     差异化策略       黑名单/
   实地考察       能力评估      四象限定位       风险预警         淘汰
   样品测试       综合定级                      动态监控
```

#### 3.2.1 供应商准入

- **在线建档**：录入基本信息、资质证书、生产范围、联系方式
- **资质审核**：营业执照、生产许可、ISO认证等，系统自动监控有效期
- **分类标签**：按产品类别、行业、地域等打标签，便于筛选
- **准入流程**：提交 → 审核 → 试用 → 正式入库

#### 3.2.2 卡拉杰克矩阵分类（核心特色）

基于 Peter Kraljic 1983年提出的采购组合矩阵，系统自动根据两个维度对供应商进行四象限分类：

| 象限 | 利润影响 | 供应风险 | 管理策略 | 典型场景 |
|------|----------|----------|----------|----------|
| **战略型** | 高 | 高 | 深度合作、战略联盟、联合研发 | 核心零部件、独家技术 |
| **杠杆型** | 高 | 低 | 竞争性招标、集中采购、压价 | 通用原材料、标准件 |
| **瓶颈型** | 低 | 高 | 保障供应、安全库存、替代开发 | 专用配件、稀缺材料 |
| **非关键型** | 低 | 低 | 简化流程、自动采购、降本 | 办公用品、通用耗材 |

系统实现：
- **自动评分**：根据采购金额占比、供应商数量、替代难度等指标自动计算坐标
- **矩阵可视化**：交互式四象限图，点击可查看供应商详情
- **策略推荐**：根据象限自动推荐管理策略
- **动态调整**：支持手动调整 + 季度自动重算

#### 3.2.3 供应商绩效评估

采用 **QCDS** 四维评估模型（行业通用标准）：

| 维度 | 权重(默认) | 指标 |
|------|-----------|------|
| **Q**uality 质量 | 30% | 来料合格率、质量事故次数、8D回复及时率 |
| **C**ost 成本 | 25% | 价格竞争力、降本配合度、付款条件 |
| **D**elivery 交付 | 30% | 准时交付率、交期达成率、紧急订单响应 |
| **S**ervice 服务 | 15% | 响应速度、技术支持、问题解决时效 |

- **自动评分**：基于历史数据自动计算各维度得分
- **等级划分**：A(≥90) / B(80-89) / C(70-79) / D(<70)
- **绩效雷达图**：可视化展示供应商各维度表现
- **趋势分析**：季度/年度绩效变化趋势
- **绩效报告**：一键生成供应商绩效评估报告

#### 3.2.4 风险预警与管控

| 预警类型 | 触发条件 | 级别 |
|----------|----------|------|
| 资质过期 | 证书到期前30/60/90天 | 高 |
| 交付异常 | 连续2次延迟交付 | 中 |
| 质量异常 | 批次不合格率>5% | 高 |
| 绩效下滑 | 评级降级 | 中 |
| 单一来源 | 物料仅1家供应商 | 高 |
| 采购集中 | 单供应商占比>40% | 中 |

### 3.3 物料管理

- **五级编码体系**：品类 - 材质 - 规格 - 供应商 - 批次（行业最佳实践）
- **物料主数据**：名称、规格、单位、图号、安全库存、采购提前期
- **物料-供应商关联**：一物料多供应商，记录报价、交期、最小起订量
- **BOM管理**：支持多级BOM，联动采购需求计算
- **呆滞预警**：超期未动用物料自动预警

### 3.4 采购管理

- **采购需求**：手动创建 / BOM自动生成
- **智能寻源**：根据物料自动匹配合格供应商，支持比价
- **采购订单**：标准订单模板，支持框架协议+按需下单
- **到货验收**：扫码/手动录入，关联质检结果
- **结算对账**：订单-入库-发票三单匹配

### 3.5 决策看板

- **采购总览**：订单量、金额、待处理、异常数
- **供应商地图**：卡拉杰克矩阵交互视图
- **绩效雷达**：多供应商绩效对比
- **风险仪表盘**：实时预警数量与分布
- **成本分析**：采购成本趋势、品类占比

## 4. UI 设计规范

### 4.1 设计原则

- **专业感**：深色侧边栏 + 浅色内容区，企业级视觉层次
- **数据驱动**：关键指标前置，图表为主，减少文字堆砌
- **操作效率**：常用操作一步到位，减少点击层级
- **信息密度**：合理利用空间，表格/列表紧凑但不拥挤

```
文字色:   #262626 (主文字) / #8C8C8C (辅助文字)
```

## 5. 数据安全与部署

### 5.1 数据安全

- SQLite 数据库文件加密 (SQLCipher)
- 本地数据自动备份（每日增量 + 每周全量）
- 操作日志审计追踪
- 用户角色权限控制（管理员/采购员/查看者）

### 5.2 部署方案

- **单机部署**：Electron 打包为 exe，SQLite 嵌入，零配置安装
- **局域网共享**：数据库文件放共享目录，多客户端连接（适合1-10人）
- **自动更新**：Electron-updater 支持增量更新
